# Diary-Entry
This is a Java terminal application built for Hack Club Snowglobe to track diaries and entries.
Click the badge below to open this project in a secure browser-based development environment:
[![Open in GitHub Codespaces](https://github.com)](https://github.com) 
Once your Codespace environment loads, copy and paste the following commands into the terminal at the bottom of the screen:

1. **Compile all Java files:**
   ```bash
   javac DiaryApp.java EntryModifier.java Tracker.java
   ```

2. **Run the application:**
   ```bash
   java DiaryApp
   ```
